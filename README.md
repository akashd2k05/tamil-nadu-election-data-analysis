# Tamil Nadu Election Data Analysis & Power BI Dashboard

## 📊 Project Overview

An end-to-end data analytics project analyzing Tamil Nadu election data to identify candidate performance, party voting patterns, vote share, winning margins, and NOTA trends across constituencies.

## 🎯 Project Objectives

- Analyze candidate-level voting performance
- Compare party-level vote performance
- Identify winners and runner-ups
- Calculate winning margins
- Analyze candidate vote share
- Evaluate NOTA voting patterns
- Build an interactive Power BI dashboard
- Generate business-style analytical reports

## 📁 Dataset

The dataset contains candidate and party-level election information.

### Dataset Summary

- **Total Records:** 4,247
- **Normal Candidate Records:** 4,013
- **NOTA Records:** 234
- **Parties:** 104
- **Constituencies:** 234

## 🔎 Analysis Performed

### Candidate Analysis

Analyzed candidate-level vote totals and identified the highest-performing candidates based on total votes.

### Party Performance Analysis

Grouped candidate records by party and calculated:

- Total votes
- Average votes
- Highest votes
- Lowest votes
- Vote range
- Average vote share

### Winner Analysis

Identified the winner and runner-up for each constituency based on candidate vote totals.

### Winning Margin Analysis

Calculated the winning margin using:

**Winning Margin = Winner Votes − Runner-up Votes**

Winning margins were categorized into:

- Close
- Moderate
- Strong
- Landslide

### NOTA Analysis

Analyzed NOTA separately from normal candidate records to avoid affecting candidate and party performance calculations.
